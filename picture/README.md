# 流程图

按业务和文件类型分目录保存流程图。图片位于 `images/`，生成脚本位于 `scripts/`。运行生成脚本会把图片写入对应的 `images/` 子目录。

## Feed

- `images/feed/latest_feed_flow.png`：最新流读取
- `images/feed/latest_feed_write_flow.png`：最新流写入
- `images/feed/following_feed_flow.png`：关注流

## Popularity

- `images/popularity/popularity_flow.png`：热度流读取
- `images/popularity/popularity_write_flow.png`：热度流写入

生成脚本：

- `scripts/feed/`
- `scripts/popularity/`
